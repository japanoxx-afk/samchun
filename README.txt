삼국지 천명 2 런처 1.1.7

수정 사항
- 1.1.6: . 키의 쉬는 일꾼 판정에서 빠졌던 기본 대기(6000)와 정지/대기(3002)를 포함합니다.
  로보워커·고블린·건축가 세 종류에 적용합니다. 작업 예약이 있으면 제외합니다.
- 1.1.5: F2로 전장 전체에서 군사 유닛을 선택합니다.
- . (마침표)로 현재 작업과 예약 명령이 없는 일꾼을 전장 전체에서 선택합니다.
  채집·이동·건설·수리 중이거나 수송 중인 일꾼은 제외합니다.
  입력창/메뉴가 열렸을 때는 두 단축키를 비활성화합니다.
  한 번에 선택 가능한 수는 아직 원본 한도인 32기입니다.
- 1.1.4: 입력창을 연 Enter 값이 다음 문자에서 다시 확정으로 처리되는 경로를 수정했습니다.
  실제 Enter/키패드 Enter 이벤트에서만 입력창을 확정합니다. 사용자가 실제 게임 입력 정상 동작을 확인했습니다.
- 랠리 방향의 건물 외곽에서 생성 위치를 탐색합니다.
  실제 배치는 원래 게임의 지형/충돌/유닛 크기 검사에 맡깁니다.
  랠리 없음/건물 내부 지정/탐색 실패 시 기존 생성 위치 탐색을 사용합니다.
  공중 유닛의 기존 높이 보정과 생산 후 자동채집을 유지합니다.
- 저장 게임이 이전 실행의 입력 잠금 객체를 덮어쓰던 충돌 경로를 수정했습니다.
  현재 실행의 잠금 객체를 유지하고 나머지 큐 데이터만 불러옵니다.
- 구버전의 잘못된 채집 대상 필드 복구를 추가했습니다.
- 전장 땅 우클릭 처리에서 빠졌던 랠리 패치를 추가했습니다.
- 생산 일꾼의 채집 대상 ID를 실제 게임 명령의 올바른 필드(+0x0E)에 기록합니다.
  1.1.0은 +0x12에 기록해 채집 대상이 0번 유닛으로 남는 오류가 있었습니다.
- 생산 함수가 끝난 뒤 건물의 원래 랠리 좌표를 읽어 기/오어 채집을 지시합니다.
  길찾기로 보정된 이동 좌표로 자원을 찾던 방식을 제거했습니다.
- 우클릭 및 게임의 수동 랠리 버튼 모두 같은 건물 랠리 값을 사용합니다.
- 자원 없음/고갈/비일꾼이면 원래 생성·이동 처리를 유지합니다.
- 원본 EXE를 보존합니다. 기존 1.1.0의 생산 함수 내부 패치는 제거했습니다.

적용
1. 현재 게임을 종료합니다. 실행 중인 구버전 게임에는 새 코드가 적용되지 않습니다.
2. dist\launcher.exe 실행 후 제목의 1.1.3을 확인합니다.
3. 랠리 패치를 체크한 상태로 게임 실행을 누릅니다.
4. 생산 건물을 선택하고 기 또는 오어에 우클릭하거나 수동 랠리를 지정합니다.
5. 새 일꾼을 생산합니다.
구버전의 대상 ID=0 / 보조 필드=자원 ID 형태를 확인해 채집 대상 필드를 복구합니다.
원본 저장 파일은 변경하지 않습니다. 실제 저장 게임의 복구 동작은 검증 중입니다.

검증 범위
- x86 빌드 및 표시 설정 120개 검사 통과.
- 생성 방향/원래 위치 대체/높이/스택 보존 20개 검사 통과.
- 1.1.3의 실제 전장 생성 위치 확인은 아직 완료하지 않았습니다.
- 패치 로직 45개 에뮬레이션 검사 통과: 실제 템플 vtable, 생성 호출의
  인수/스택/레지스터 보존, 자원/고갈/비일꾼 처리 포함.
- 실행 중 게임을 읽기 전용으로 복사한 격리 에뮬레이션에서 실제 자원
  12개에 대한 기/오어 명령과 정확한 대상 ID 전달 확인.
- 동일 검사에서 실제 전장 입력 함수의 땅/자원 랠리 명령 생성 확인.
- 멈춘 기존 일꾼의 잘못된 대상 ID=0 확인. 이동 명령의 큐 등록과
  게임의 취소 처리 함수가 해당 잘못된 채집 상태를 해제하는 것 확인.
- 위 검사는 실행 중 게임 메모리를 수정하지 않습니다.
- 2026-10-03 사용자 실제 플레이 확인: 수동 지정/우클릭으로 자원 랠리를
  지정하면 생산 직후 일꾼이 자동채집합니다.
- 자원 반납의 반복 주기 및 모든 자원/종족 조합은 별도 검증하지 않았습니다.
- 1.1.2 실행에서 시작 직후 종료는 재현되지 않았습니다.
- 멀티플레이 및 모든 종족/맵 조합은 미검증입니다.
