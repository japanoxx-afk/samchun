# samchun

삼국지 천명 2 (3KD2 1.20g) Windows 런처 및 호환성 패치.

게임 원본과 게임 데이터는 포함하지 않습니다. 지원 원본 SHA256:
`A0EE96931B3B74FCE739062D8E58253892510EF863E9127648AC38FD4D515F99`

## 현재 기능

- 창모드, 출력 해상도 및 16:9 늘림 설정
- 건물 우클릭 랠리, 자원 랠리 자동채집, 랠리 방향 생성
- 입력창 수정, F2 군사 선택, 마침표 대기 일꾼 선택 (최대 32기)

기존 게임 EXE는 보존하고 별도의 패치 실행 파일을 생성합니다.
마나 65%, 32기 초과 선택, 복수 건물 동시생산, 순차 마법시전은 아직 구현하지 않았습니다.

## 개발

Windows .NET Framework 4 C# 컴파일러를 사용합니다. 게임 패치 생성에는
Python의 pefile, 테스트에는 unicorn과 capstone이 필요합니다.
`tools/build_game_patch.py`로 패치 리소스를 만들고 `build.ps1`로 런처를 빌드합니다.
게임 경로와 테스트 전제는 각 도구를 참고하세요.
