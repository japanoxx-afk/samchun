삼국지 천명 2 런처 패치노트

1.3.11 — 우클릭 랠리 효과음
• 땅·기·오어에 우클릭으로 랠리를 지정하면 수동 지정과 같은 효과음 재생.
• 실제 우클릭 명령 전달 시 한 번만 재생. 커서 이동·미리보기에는 재생하지 않음.

1.3.10 — 건물 패치 제거 / 패치노트
• 생산건물 복수 선택·동시 생산 변경 제거.
• 건물 선택, 생산 메뉴와 생산 버튼을 원본 방식으로 복원.
• 런처에 패치노트 버튼 추가. 인터넷 없이 내역 확인 가능.

1.3.9 — 군사 선택 누락 개선
• F2 선택 시 이동 분류가 다른 군사 유닛이 빠지던 조건 수정.
• 실제 유닛 ID 범위를 기준으로 판별하고 일꾼·건물 등 제외.

1.3.8~1.3.9 — 생산건물 복수 선택 / 동시 생산 시도
• 실제 플레이에서 동작하지 않아 1.3.10에서 관련 변경 제거.

1.3.7 — 64기 선택 / 순차 마법
• 유닛 선택과 부대 지정·호출을 최대 64기로 확대.
• 마법 클릭 한 번에 시전 가능하고 마나가 충분한 한 기만 시전.
• 다음 클릭은 이후의 시전 가능한 유닛으로 이어짐.
• 기존 저장 형식 유지: 저장 후 불러오면 선택·부대 지정은 앞의 32기만 복원. 실제 유닛 수는 유지.

1.3.6 — 초기 마나 65%
• 생산된 유닛의 마나를 최종 최대치의 65%로 설정(소수점 버림).
• 기존 유닛과 저장된 마나는 유지.

1.3.5 — 인터넷 방 / 진영 선택
• 방 퇴장 후 다시 방 생성 시 network create game error 수정.
• 진영 목록에 랜덤만 나오던 응답 수정.

1.3.4 — 계정 전적
• 인터넷 대전 종료 결과를 계정별 승패 기록으로 누적.
• 재로그인·서버 재시작 후에도 전적 유지. 같은 결과 중복 집계 방지.
• 원본이 미집계로 보내는 짧은 경기·중단·무효 결과는 제외.

이전 개선 내역
• 창모드와 출력 해상도 선택, 16:9 화면 채우기 지원.
  출력 크기 확대이며 전장 시야 범위는 원본과 동일.
• 건물 선택 후 땅·기·오어 우클릭으로 랠리 지정.
• 자원 랠리로 생산된 일꾼의 자동 채집 및 랠리 방향 생성 위치 개선.
• 싱글플레이 Enter 입력창이 키 입력 시 닫히던 문제 수정.
• F2 전장 군사 선택, . 쉬는 로보워커·고블린·건축가 선택.
• GitHub 런처 업데이트: 다운로드 검증, 백업, 교체·재시작.
• 인게임 INTERNET 호환 서버: 회원가입·로그인·공용 대기실·방 목록.
• 런처에서 인터넷 서버 구동과 서버 IP 설정.
• 자체 회원가입 입력 길이 제한 완화. 게임 입력창·통신 형식 제한은 유지.
• 인터넷 응답속도 변경은 사용자 요청에 따라 롤백.
